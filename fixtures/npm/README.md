# npm fixtures

Lock files with **known vulnerable** versions, used by tests. Do not install them.

| Folder | What it covers |
|---|---|
| `lock-v3-express` | `package-lock.json` v3 generated by npm: express 4.17.1 (+ transitive body-parser, qs…), lodash 4.17.15, dev minimist 1.2.0 |
| `lock-v1` | Hand-written lockfile v1: nested `dependencies`, `requires`, a git dependency |
| `workspaces` | npm workspaces: link entries, nested `packages/web/node_modules/minimist` 0.0.8 |
| `manifest-only` | `package.json` without a lock file: ranges, `file:` and `npm:` alias specs |
| `pnpm-v9` | `pnpm-lock.yaml` v9 generated by pnpm 12: workspace importer, peer-suffixed snapshot (`react-dom`) |
| `yarn-v1` | Classic `yarn.lock`: multi-spec entries, `npm:` alias, git dependency, workspaces |
| `yarn-berry` | Berry `yarn.lock` (v8 metadata): workspace entries, `patch:` protocol |
