# SwiftPM fixtures

Hand-written `Package.resolved` files; revisions are placeholders. Old versions (`swift-nio 2.30.0`, `Alamofire 5.0.0`) are intentional for demos. Never resolve them.

| Folder | What it covers |
|---|---|
| `app` | v3 pins with `Package.swift` (direct vs transitive), a branch pin and an SSH URL (skipped) |
| `legacy-v1` | v1 format (`object.pins`, `repositoryURL`) |
